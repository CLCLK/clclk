# 일어나 출근해야지

오전 7시부터 실제 60초 안에 캐릭터를 깨우는 브라우저 게임입니다. 실제 1초마다 게임 속 시계가 1분씩 흐릅니다.

## 실행하기

상위 실습 프로젝트에서 `python practice-01/preview_server.py start`를 실행한 뒤 <http://127.0.0.1:8000/wake-up-for-work/>를 엽니다. 이 게임 폴더만 따로 복제했다면 `index.html`을 브라우저에서 열어도 실행됩니다.

1. 웹캠 화면 표시를 켜면 게임 화면에 테스트용 자리가 생깁니다. 이 버전에서는 테스트 버튼으로 플레이합니다.
2. **게임 시작**을 누르면 3초 뒤 7시부터 시작합니다.
3. **웃기**, **손 흔들기**, **주먹 쥐기**, **브이** 중 하나를 누를 때마다 졸음이 10씩 줄어듭니다. 8시 전에 10번 누르면 성공합니다.
4. 결과 화면의 **다시 시작**을 누르면 시작 화면으로 돌아갑니다.

## 수정할 곳

| 파일 | 역할 |
| --- | --- |
| `index.html` | 시작, 게임, 결과 화면의 문구와 배치 |
| `style.css` | 색과 크기, 모바일 화면 배치 |
| `script.js` | 카운트다운, 시계, 졸음 계산과 화면 전환 |
| `motion-input.js` | 동작 이름과 게임으로 동작을 전달하는 통로 |
| `bedroom.webp` | 시작·게임 화면의 침실과 캐릭터 |

나중에 MediaPipe Tasks Vision에서 새로운 동작이 확인되면 `motionInput.emit("smile")`처럼 동작 이름을 한 번 전달합니다. `motion-input.js`의 이름 목록에 맞추면 버튼 입력과 같은 규칙이 적용됩니다. 인식 결과가 영상의 여러 프레임에 연속으로 나온다면, 동작이 처음 확인된 순간에 한 번 전달합니다.

## 침실 그림

내장 ImageGen으로 만들었습니다. 첫 번째 참고 이미지의 방 배치, 코발트색 손그림 윤곽선과 종이 질감을 바탕으로 했습니다. 두 번째 이미지에서는 모서리 창과 침대, 옷걸이, 냉장고, 낮은 원형 테이블의 배치를 참고했습니다. 세 번째 이미지에서는 둥근 얼굴, 두꺼운 눈썹, 가늘게 감긴 눈, 분홍빛 볼과 작은 타원형 입을 참고했습니다.
