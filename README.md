# 일어나 출근해야지

오전 7시부터 실제 40초 안에 캐릭터를 깨우는 브라우저 게임입니다. 실제 40초 동안 게임 속 시계는 07:00에서 08:00까지 흐릅니다(실제 1초 = 게임 속 1.5분).

## 실행하기

상위 실습 프로젝트에서 `python practice-01/preview_server.py start`를 실행한 뒤 <http://127.0.0.1:8000/wake-up-for-work/>를 엽니다. 웹캠을 사용할 때는 이 주소를 Chrome이나 Edge에서 열고 카메라 권한을 허용합니다. MediaPipe와 모델을 처음 불러올 때 인터넷 연결이 필요합니다.

1. 페이지를 열면 웹캠 연결을 요청합니다. **웹캠 화면 표시**는 기본 ON이며, 첫 방문에는 브라우저에서 카메라 권한을 허용해야 합니다. **미리보기**로 얼굴과 어깨를 확인합니다. 표시를 OFF로 바꿔도 웹캠 연결과 게임 중 모션 인식은 유지되고 창문 영상만 숨겨집니다. 권한이 없을 때도 버튼으로 플레이할 수 있습니다.
2. **게임 시작**을 누르면 3초 뒤 협탁의 시계가 07:00부터 흐릅니다.
3. **흔들기**, **간지럽히기**, **소음 내기**, **바람 쏘기**를 클릭하면 버튼이 눌린 상태로 잠시 표시되고 졸음이 10씩 줄어듭니다. 같은 공격은 두 번째 연속 사용부터 효과가 없으며 다른 공격을 성공시켜야 다시 쓸 수 있습니다. 이 규칙은 버튼과 모션에 똑같이 적용됩니다. 반복 시도 시 화면 중앙에 “같은 방법을 연속으로 쓰면 효과가 없어요. 다른 방법으로 깨워주세요.”가 1초 표시됩니다. 게임 시간은 계속 흐르며, 다른 공격이나 화면 이동 시 팝업을 닫습니다. 8시 전에 졸음이 0이면 성공합니다.
4. **흔들기**를 누르면 침대와 방 소품이 흔들립니다. **SOUND**로 흔들림 소리를 켜고 끌 수 있습니다.
5. 성공과 실패는 같은 방 안에서 이어집니다. 하단의 **돌아가기** 또는 결과 문구 아래의 **시작 화면**은 진행 중인 타이머와 효과를 멈추고 첫 화면으로 돌아갑니다. 하단의 **다시 하기**는 새 라운드를 시작합니다. 웹캠 연결은 이 화면 이동 중에도 유지되며 페이지를 떠나면 종료됩니다.

**흔들기 모션**은 양 주먹을 쥔 채 창문을 두드리듯 카메라 쪽으로 내밀었다 거두는 동작입니다. 손 크기 또는 손목 이동 방향이 바뀌는 것을 확인하며 정확히 출발 위치로 돌아올 필요는 없습니다. 양손 모두 1초 이상 왕복하면 한 번 인식하고 다음 1초를 자동으로 셉니다. **웹캠 화면 표시**를 OFF로 해도 카메라 권한을 허용하면 손 인식을 사용할 수 있습니다.

졸음이 100~51이면 깊은 잠, 50~21이면 얕은 잠, 20~1이면 거의 깬 표정이 나옵니다. **간지럽히기**로 잠깐 웃은 뒤에는 현재 졸음에 맞는 표정으로 돌아옵니다.
**간지럽히기 모션**은 양손의 나머지 손가락을 자연스럽게 접고 검지를 구부렸다 펴는 동작입니다. 검지를 완전히 펴지 않아도 굽힘 정도의 변화로 판정합니다. 두 검지가 각각 움직이는 상태를 2초 이상 이어가면 한 번 인식하고 다음 2초를 자동으로 셉니다. 양손 타이밍은 달라도 됩니다. 검지를 가만히 들거나 한 손만 움직이는 경우에는 발동하지 않습니다. 계속 같은 모션을 해도 인식은 이어지지만 같은 공격의 연속 효과는 게임 규칙에서 막습니다.

**소음 내기 모션**은 입을 크게 벌린 상태를 1초 유지하는 동작입니다. 마이크와 실제 소리는 사용하지 않습니다. 얼굴에서 입의 벌어진 비율을 읽고, 잠깐 가려지는 경우 약 0.35초까지 진행을 보존하되 가려진 시간은 더하지 않습니다. 계속 벌리고 있으면 다음 1초를 자동으로 세며, 같은 공격의 연속 효과는 게임 규칙에서 막습니다. 웹캠 화면 표시가 OFF여도 같은 카메라 영상으로 인식합니다.

**바람 쏘기 모션**의 화면 안내는 “두 손을 붙여 앞으로 장풍 쏘기”입니다. 실제 판정은 펼친 두 손이 1.5초 동안 보이면 인정하며, 손 사이 거리·높이·앞으로 미는 움직임은 요구하지 않습니다. 한 손, 주먹, 검지 자세는 제외합니다. 약 0.65초 이하의 인식 누락은 진행을 보존하되 누락 시간은 세지 않습니다. 계속 유지하면 다음 1.5초를 자동으로 세고 연속 공격 제한은 그대로 적용합니다. 웹캠 표시 OFF에서도 작동합니다.

손이 잠깐 가려지는 경우 약 0.65초까지 진행을 유지합니다. 게이지 아래에는 흔들기·소음 내기 1초·간지럽히기 2초·바람 쏘기 1.5초 진행 상황과 반복 공격 안내가 표시됩니다. 입을 벌려 판정 중일 때는 얼굴 동작의 진행 안내를 우선 표시합니다.
**소음 내기**는 공사 충격선과 도로의 속도선을, **바람 쏘기**는 창에서 이불로 흘러가는 파란 바람선을 보여 줍니다.

## 수정할 곳

Pages 배포에서 이전 UI가 캐시에 남지 않도록 `index.html`의 CSS·JS 주소에 버전(`?v=20261112-tuning1`)을 붙였습니다. CSS·JS를 수정해 다시 배포할 때 이 버전도 함께 변경하고, 공유할 게임 주소에도 같은 `?v=...`를 붙이면 이전 HTML 캐시까지 피할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 시작, 게임, 결과 화면의 문구와 배치 |
| `style.css` | 색과 크기, 모바일 화면 배치 |
| `start-screen.css` | 시작 화면과 동작 선화 배치 |
| `game-screen.css` | 게임 화면 하단 UI와 방의 흔들림 |
| `result-scene.css` | 승패 연출과 결과 문구의 디졸브 |
| `script.js` | 카운트다운, 시계, 졸음 계산과 화면 전환 |
| `room-effects.js` | 소음과 바람을 표현하는 그림과 움직임 |
| `motion-input.js` | 동작 이름과 게임으로 동작을 전달하는 통로 |
| `window-camera.js` | 카메라 연결, 얼굴·어깨 위치 맞춤, 배경 제거, 통창 합성 |
| `shake-motion.js` | 양 주먹과 앞뒤 움직임을 판정해 흔들기를 실행 |
| `tickle-motion.js` | 양손 검지의 굽힘·펴짐과 2초 지속을 판정 |
| `hand-motion.js` | 하나의 MediaPipe 손 인식 결과를 공유하고 세 손 공격의 중복 판정을 방지 |
| `wind-motion.js` | 펼친 양손과 1.5초 유지를 판정 |
| `guide-wind-palms.png` | 시작 안내와 게임 버튼이 함께 사용하는 장풍 자세 선화 |
| `face-motion.js` | 얼굴의 입 벌림과 1초 유지를 판정해 소음 내기를 실행 |
| `game-room-backdrop.webp` | 창틀과 파란 통창이 포함된 고정 배경 |
| `game-room.webp` | 움직이는 침대·가구의 원본 |
| `game-room-tickle.webp` | 내장 ImageGen으로 만든 간지럽히기 표정. 방 그림에서 얼굴 부분만 겹칩니다. |
| `game-room-shallow.webp`, `game-room-near-awake.webp` | 얕은 잠과 거의 깬 표정 |
| `result-victory.webp`, `result-empty-bed.webp`, `result-failure-face.webp` | 승리 캐릭터, 빈 침대, 패배 표정 |

나중에 MediaPipe Tasks Vision에서 동작 판정을 마치면 `motionInput.emit("shake")`처럼 동작 이름을 전달합니다. `motion-input.js`의 이름 목록에 맞추면 버튼 입력과 같은 통로를 사용합니다.

동작 판정 자동 검사는 이 폴더에서 `node --test tests/hand-motion.test.cjs tests/face-motion.test.cjs`로 실행합니다. 가상 관절 입력으로 시간·반복·중복 발동을 확인하며, 실제 웹캠 인식 정확도는 별도로 체험하며 조정해야 합니다.

## 침실 그림

장풍 안내 그림은 내장 ImageGen으로 기존 복싱 자세 선화를 편집했습니다. 사용한 프롬프트 요지: "기존 남색 둥근 선과 단순한 얼굴을 유지하고, 양팔을 앞으로 내밀어 펼친 두 손바닥을 가까이 나란히 보여 주는 자세로 변경. 손은 겹치지 않게, 각 손가락 5개, 투명 배경, 글자 없이." 원본 출력은 `guide-wind-palms.png`에 보존했습니다.

내장 ImageGen으로 만들었습니다. 첫 번째 참고 이미지의 방 배치, 코발트색 손그림 윤곽선과 종이 질감을 바탕으로 했습니다. 두 번째 이미지에서는 모서리 창과 침대, 옷걸이, 냉장고, 낮은 원형 테이블의 배치를 참고했습니다. 세 번째 이미지에서는 둥근 얼굴, 두꺼운 눈썹, 가늘게 감긴 눈, 분홍빛 볼과 작은 타원형 입을 참고했습니다.

게임 배경은 v5 구도를 바탕으로 내장 ImageGen에서 창틀과 바닥을 이어 그려 만들었습니다. `game-screen.css`에서 두 창 안의 영상 자리와 침대·가구의 윤곽을 따로 지정해, 흔들기 중에도 창은 고정됩니다.
